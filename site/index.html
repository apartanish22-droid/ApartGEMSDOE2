How to submit on DrivenData

  1. Log in to drivendata.org/competitions/306/competition-doe-gems.
  2. Go to Make a Submission → File to submit → choose a single-band GeoTIFF (.tif) (values must be in [0,1] — this writer enforces it).
  3. Give it a unique name and a short note (e.g. "clustering with k=25").
  4. Confirm the TIF matches the submission format's CRS, shape, and geotransform, then submit.

Error you saw, "Predicted values must be in range [0, 1]": this repo's writer clips all values to [0,1] before writing, so regenerated TIFs will not trigger it.
