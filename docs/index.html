How to submit — once a candidate passes all gates

  1. Obtain the official sample format and competition data from DrivenData; confirm the current rules.
  2. Use the canonical spatially buffered hide-and-recover evaluator; beat the comparable holdout best and document confidence intervals and leakage canaries.
  3. Compare candidate surface and final dots against every registry raster; fail if rank correlation >0.90 or dot overlap within 3 pixels >70%.
  4. Run python scripts/validate_tif.py sample_submission.tif candidate.tif and save its JSON. It checks a single float band, grid, footprint, finite pixels and [0,1] range. A pass is format only, never authorization.
  5. After independent selector approval within the weekly cap, upload the validated TIFF on the competition submission page, with a unique name and note (max 140 characters). Save the organizer receipt.

If you see “Predicted values must be in range [0, 1],” do not submit again until the pixel range check passes; renaming the file cannot repair its pixels.
