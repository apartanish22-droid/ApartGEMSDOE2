02 / What the evidence says

Why did the leader stand out?

We can explain the geometry, not establish the cause of a reported score without the hidden labels and a file-bound receipt.

Verified file geometry

Less redundancy, not a new detector.

The GEMSDOE32 archival dot set is contained in the GEMSDOE31 set. The former removes 2,545 dots; every removed dot lies within two pixels of the mirrored known catalogue. This is a geometry audit, not a leaderboard result.

Under the organizer’s distance-weighted metric, tightly clustered predictions can compete for the same nearby credit while contributing prediction mass. Pruning could help, but this does not prove why the reported value was higher or that it will generalize.

The gate that stops this run

A literal uniqueness conflict.

≥ 82.34%

Minimum possible 3-pixel overlap with one registered calibration lattice at the champion’s 37,654-dot count — above the requested 70% limit. Only 6,649 mirrored-footprint cells are outside the lattice’s 3-pixel neighborhood.

This is a counting bound, not a score. It does not rule out every smaller candidate, and it does not justify moving dots into holes to game the rule.
