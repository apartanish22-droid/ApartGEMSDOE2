02 / Why the reported leader?

Emission geometry, not proof of geology.

The GEMSDOE32 dot set is a strict subset of the GEMSDOE25 and GEMSDOE31 sets. Removing low-value or redundant predictions can improve the distance-weighted metric, but the hidden truth and score receipt are unavailable. Causation—and an improvement over the reported value—remain unproven.

03 / No shortcuts

What must clear before release

  • Explicit method lane and complete, current registry
  • Feature-by-feature leakage canaries and buffered segment holdout
  • Paired improvement against the comparable holdout best
  • Surface and final-dot novelty, plus exact-byte format validation
  • Separate weekly-slot selection; format alone never authorizes upload
