How to make a competition submission (exactly)

Current instruction: do not submit. This repo's only new file failed its scientific gates (see decision page). Follow the steps below only for a future file whose run card says verdict: promote / OK TO SUBMIT. Submitting a negative file wastes a weekly slot.
  1. Pick the portal-safe file: the -zeros.tif (whole array finite in [0,1]). Never upload the -nan.tif twin through the web form — NaN triggers “Predicted values must be in range [0, 1]” even though the written spec allows NaN outside the footprint.
  2. Verify locally first (must PASS):
    GEMS_DATA_DIR=/tmp/gems_data .venv/bin/python scripts/check_submission.py docs/downloads/<file>-zeros.tif --strict-finite
    Require: single band, float32, EPSG:32611, 3730×3292, template transform, in-footprint [0,1], whole-array [0,1].
  3. Open the competition: DOE GEMS Prize → Submissions → New submission.
  4. File to submit: choose the single -zeros.tif (or the single-TIFF -zeros.zip containing exactly that one GeoTIFF).
  5. Unique name / Note: paste the run card's name and ≤140-char note verbatim so the slot is traceable to its SHA-256. Current research file (for illustration — do not submit it):
    Name: apartgemsdoe2-ap1-dilatcond-37654-20261027-1f26aa05-zeros
    Note: AP-1 dilat+cond+base+grav coincidence 37654d B2 | HOLDOUT-DTI 0.0389 vs champ 0.0992 | 1f26aa05 | DO NOT SUBMIT
  6. Create submission, then save the submission-page receipt (score + file hash) back into evidence/ — only then may a score be called ORGANIZER-CONFIRMED. Without a receipt it stays OWNER-REPORTED.
  7. Weekly cap: promotion is a separate selector decision within the cap shown on the submission page. One slot per experiment; never resubmit an already-scored file (e.g. GEMSDOE32 B2 0.2778).

Format rules (official, page 967, fetched 2026-10-27): same CRS (EPSG:32611), 100 m, same bounds, single-band float32, values in [0,1]; metric DTI α=0.2, β=0.8, R=300 m triangular kernel. Guidance PDF: NLR FY26OSTI 96647 (organizer submission guidance, as supplied in brief).
