4. Why GEMSDOE32's reported 0.2778 is not a file you should copy

  • GEMSDOE32's h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros (B2) is a two-pixel-collared, catalogue-near subset of the D2.8 dot set that GEMSDOE24/GEMSDOE25/GEMSDOE30 also filed (100.0% dot overlap between GEMSDOE24, GEMSDOE25 and GEMSDOE30 bests).
  • Its dots fall within 3 px of catalogue faults, so under the distance-weighted Tversky metric it carries false-positive weight where the hidden truth expects new faults — a mechanism, not a measured organizer score.
  • The value 0.2778 is user-reported with no submission-page receipt; it does not appear on the public leaderboard top-50 rows observed in this review.
  • Copying it under a new name is explicitly prohibited: a changed filename, encoding, or hash is not a new geological method.
