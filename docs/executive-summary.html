Hypothesis — H-BLIND-CONDUIT (rank 1 of 5)

Layers: radiometric potassium-enrichment proxy, magnetic demagnetization proxy, curvature-convergence proxy — combined multiplicatively on the competition grid.

Physical signature: concealed geothermal faults lacking surface scarps but hosting hydrothermal alteration that enriches potassium (radiometric anomaly) and demagnetizes host rock (magnetic deficit), with curvature convergence at structural nodes.

Why it catches catalogue-missing faults: buried / alluvial-covered faults control alteration halos without requiring a visible scarp or catalogue trace.

How it differs from all prior work in this repo: H1 uses radiometric × DEM curvature (surface-expression dependent); dotted-ridge/scarp families use catalogue-distance; H-RAD-MAG-CONTRAST uses gradient products; GEMSDOE36 uses a black-box PINN. H-BLIND-CONDUIT is the first structural-preparation × radiometric × magnetic convergence lane with explicit catalogue masking.

Named non-fault mimics: uneven crustal radioactivity / igneous-contact boundaries (radiometric anomalies without faults); mafic/ultramafic contacts (magnetic deficits without faults); concave mass-wasting terrain (curvature convergence without faults).

04 / Step-by-step: how to submit

Making a submission into the contest

  1. Download the TIF file above (click the ⬇ Download TIF button).
  2. Go to the DrivenData GEMS competition submission page: competition page ↗.
  3. Click "New submission" and choose the downloaded .tif file.
  4. Enter a submission name (unique, e.g. the file stem shown above).
  5. Enter a short note (≤140 characters) to help tell submissions apart, e.g. clustering with k=25 style.
  6. Click Submit. Save the submission-page receipt and the file SHA-256 together.

Format requirements: single-band GeoTIFF (.tif) or .zip containing one GeoTIFF; must match CRS (EPSG:32611), shape (3730×3292), and geotransform; predicted values must be in range [0, 1].

Known portal error: "Predicted values must be in range [0, 1]" — this file is guaranteed finite in [0,1] across the whole array (zeros outside footprint), which avoids sentinel/NaN/out-of-range causes.
