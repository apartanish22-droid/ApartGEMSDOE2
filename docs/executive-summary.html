02 / How to submit

Step-by-step: download → upload.

DrivenData accepts a single-band GeoTIFF (.tif) or a .zip containing one GeoTIFF. It must match the competition grid (EPSG:32611, 3730 × 3292, 100 m).

1 / DOWNLOAD

Get the file

Click the Download submission GeoTIFF button at the top of this page (or the .zip bundle). Save gemsdoe32-unique-blind-conduit-20261030T021414Z-70aa4159-zeros.tif. This is the unique, format-validated submission.

2 / OPEN THE PORTAL

New submission

Go to the DrivenData GEMS competition submission page, choose File to submit, and select the downloaded .tif (or .zip). Add the short note below in the Note field.

3 / ADD THE NOTE

Paste the note

Use a unique name and a short comment (≤140 characters) so you can tell submissions apart later (e.g. clustering with k=25):

ApartGEMSDOE2 unique blind-conduit: subsurface gravity/mag/radiometric/seismic anomaly dots, collar-pruned, 37654 dots B2 (holdout est only)

Upload and record

04 / Method & uniqueness

Why this is a unique submission.

The nine focus-site files all reproduce the same dotted-catalogue geography (pairwise overlap 86.72–100%). This file takes a different physical lane.

Hypothesis

Blind geothermal conduits express as coincident subsurface anomalies.

Concealed faults missing from the USGS/INGENIOUS surface catalogue should show hydrothermal-alteration and fluid-pathway signatures in gravity gradient, magnetic gradient, radiometric edge and seismicity-density layers — not just topographic scarps already mapped.

Physical signature

Normalized gravity-edge × magnetic-edge × radiometric edge × seismicity, belief-weighted.

A soft combined belief surface (0.35 grav + 0.25 mag + 0.20 rad + 0.20 seis), dots packed by exact marginal-credit greedy emission confined to the belief support, then catalogue-collar pruned (2 px). No distance-to-catalogue look-up (that channel is leakage on visible faults).

Non-fault mimics

Igneous contacts, lithologic boundaries, erosion scarps, alluvial fans.

These can produce gradient or radiometric anomalies without faults; each feature was screened against the holdout before combination (no single-feature AUC above 0.90).

Uniqueness vs registry

0% within 3 px of any of the 9 focus rasters; |ρ| ≈ 0.01 vs all.

Pre-placement surface check: rank-correlation with every registry raster ≤ 0.90. Final-dot check: ≤ 70% within 3 px of any registry raster (measured 0.0%). Literal lane rule passed.
